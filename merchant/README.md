# 食联网数智餐饮平台商户端（本地原型）

本目录是线上商户端原型的本地高保真副本，保留原有页面视觉、示例数据与前端交互。

## 启动方式

双击：

```text
双击启动商户端原型.bat
```

或在本目录打开 PowerShell，运行：

```powershell
./start-prototype.ps1
```

浏览器访问：

```text
http://localhost:4174/
```

停止服务时，在 PowerShell 窗口按 `Ctrl+C`。

## 页面入口

- 登录页：`http://localhost:4174/`
- 组织及人员：`http://localhost:4174/食联网数智餐饮平台-组织及人员.html`

## 已包含功能

- 用户登录、商户选择、找回密码。
- 组织切换、组织档案与成员维护。
- 角色管理、管理员设置、账户菜单。
- 按组织维护统一菜谱库，菜谱来源分为“租户授权”和“自建”。
- 从租户授权范围选择并同步菜谱到当前组织。
- 租户菜谱分类只读查看，创建和编辑时使用租户统一字典。
- 纯人工及含设备加工菜谱的新建、编辑、上下架、复制和删除。
- 在菜谱详情中查看当前版本和最新授权版本，并主动确认更新。
- 基础信息 › 供应商管理：只读查看本商户可采购的供应商（由租户端按商户绑定下发），含供应类型、联系人、资质证照与供货范围详情。
- 基础信息 › 档口管理：档口的增删改查、负责人、经营餐次与营业时间。
- 商品中心：商品/SKU 维护、分类、加工形态，以及「关联标准食材」——采购计划选商品就依赖这个关联关系。
- 计划管理 › 排餐计划：组织层档口总览 + 档口周排餐表（排餐是采购计划的上游输入）。
- 计划管理 › 生产计划：按排餐派生生产任务。
- 计划管理 › 采购计划：选档口 → 采购计划列表 → 新建 → 详情三页签（商品映射 / 采购明细 / 询价单，含比价与定标）。
- 采购管理 › 采购订单（**V4.0 两层框架**）：**第 1 层 订单列表**（下单方切换 + 5 张订单口径统计卡（订单总数 / 订单验收总金额 / 本月订单数 / 本月订单验收总金额 / 待我验收完成订单数）+ 筛选（供应商 / 订单编号 / 来源 / 送达日期，送达日期默认**今天前后 15 天**，点 `查询` 生效、`重置` 还原）+ **订单状态平铺页签**（全部状态 / 待确认 / 已确认 / 待验收 / 验收中 / 已完成，带张数）+ **售后平铺页签**（全部 / 有售后 / 无售后，带张数）+ 11 列订单表（订单编号 / 供应商 / 来源+来源单号 / 送达日期 / 品项 / 订单总金额 / 验收总金额 / 订单状态 / 是否有售后 / 创建时间 / 操作））
- **第 2 层 订单详情（商品明细整页）**：页头（`← 返回订单列表` / 订单编号 + 来源 + 状态 / 摘要行 / `更多信息`（7 项，**默认收起**）/ `修改订单`（仅待确认 + 直采））→ 商品明细 11 列（含**行级验收 / 验收详情 / 退货·售后详情**）→ 发货记录 / 售后记录 / 状态时间轴 / 供应商模拟。验收逐行进行、可反复修改并留痕；验收完成需全部行已验收 + 电子签名，完成后订单锁定。
- 新建入口 `+ 新建订单` **直达直采三步向导**（送达日期与数量 → 总览 → 收货与提交；**V4.2 起没有「选供应商」步**）：
  - 商品池 = **该档口在售 + 已绑定供应商 + 该供应商有报价**的 SKU（取自供货关系管理），未绑定的商品不出现
  - 数量表格：图片 / 商品名称 / **供应商** / 单位 / 规格 / 品牌 / 单价 / **总价（采购量 × 单价，随填随算）** / 形态 / 采购量 / 备注 / 删除
  - 总览：**1 张摘要卡**（合计金额大数 + 4 个统计块 + 供应商 chip）+ **1 个供应商 1 张卡片**（卡头带小计，按小计金额降序）
  - 提交时按 **（送达日期 × 供应商）拆单**，一张订单仍只有 1 家供应商；有商品未填量 / 未选收货人都会拦截。
- **V4.0 变更（2026-10-29）**：①**删除采购单层**（不再有 `CG…` 单号、「含 N 张订单」、采购单列表 / 详情页，数据里只有订单）；②**商品明细由抽屉改为整页**；③**取消「订单信息」卡片**，改为页头「更多信息」展开；④订单状态 / 售后筛选上移到列表并沿用平铺页签风格；⑤送达日期默认今天±15 天，移除「全部 / 某天」日期页签；⑥**询价整体下线**（询价单 tab、询价单列表 / 详情、比价 / 定标、询价下单向导、「选下单方式」弹窗）。
- 采购管理 › **供货关系管理**（**V4.1 新增**）：按**档口**维护「商品 SKU × **1 家**供应商」的供货关系（一对一、覆盖式写入）。列表 = 下单方切换 + 4 张统计卡（可绑定 SKU 数 / 已绑定 / 未绑定 / 无供应商报价 SKU 数；「暂无报价」不单独占卡，按行内「绑定状态」显示）+ 筛选（关键词 / **商品分类三级弹层**（与「添加商品」同一套交互，任一层可选）/ 形态 / 绑定状态 / 供应商 / `包含已下架`）+ 批量操作条（3 个按钮右对齐，无范围提示文案）+ 12 列关系表（图片 / 商品名称 / SKU 编码 / 单位 / 规格 / 形态 / **商品分类（三级全路径）** / 当前供应商 / 最低报价 / 最近采购 / 绑定状态 / 操作；**无勾选列**）。
- **单个 SKU 选择供应商**：抽屉只列**能供应本 SKU 形态**的供应商（净菜商品看不到毛菜供应商），显示该商品报价与「最近采购」标记；该商品**没有任何供应商报价**时，下拉只给一条 `该商品暂无供应商报价`，**仍可保存**（记为「暂无报价」态）。
- **批量操作（统一作用于该档口全部在售商品，不受筛选影响）**：①`一键选择报价最低供应商`——报价相同时先选**最近一次采购过**的供应商，没有采购史则选**供应商 ID 较小**者；允许覆盖已有绑定，可重复点击（幂等）；点击**先弹二次确认**「是否一键选择最低报价供应商，如有商品已绑定供应商，将会做覆盖处理」，`确认` 才执行、`取消` 不改动；②`按形态批量绑定`——选 1 个形态 + 1 家能供该形态的供应商，覆盖该形态全部在售 SKU，预览里提示覆盖数量；③**`一键清除供应商`**（原「批量解绑」）——只清除已绑定记录，点击先弹二次确认「是否一键清除所有已绑定的供应商」。
- **下架不清除绑定**：已下架 SKU 默认隐藏，勾选「包含已下架」后**灰态只读**展示（保留原绑定）；三个批量操作的作用范围都只含在售 SKU，不会动下架 SKU 的关系。
- **V4.1 范围说明**：本轮**只做关系维护，不改下单流程**——直采新建订单的商品池仍取「该供应商有报价的商品」，按供货关系过滤商品池放到下一版（PRD D48）。

## 工作流约定：本地优先，不擅自发布

**本目录（`merchant-recipe-annotated`）是商户端原型的唯一真源，改原型只改这里。**

| 动作 | 是否允许 | 说明 |
| --- | --- | --- |
| 改本目录的 js / css / html / PRD / tools | ✅ 默认就这么做 | 改完在本目录起服务预览 |

## 说明

- 原型为纯前端静态应用，无需安装依赖。
- 数据为演示数据，刷新页面后恢复初始状态。
- **讲解演示小工具**：L3 商品明细抽屉里，「售后记录」卡头有 `模拟售后单`，点一下即写入一条售后单（不用手工走供应商退货流程），再用底部供应商模拟区的 `认可售后` / `不认可售后` 演示两种结果；写入后刷新即恢复。
- **直采下单第 2 步（V2.0.23）**：按送达日期生成**日期页签**（tab 右侧 × 可单独删除该日期、可恢复），选中某天后只编辑**当天**要采购的商品；行字段 = 图片 / 商品名称 / 单位 / 规格 / 品牌 / 形态 / 采购量 / 备注 / 删除；右上「+ 添加该日商品」抽屉支持**商品名称 + 拼音首字母模糊搜索**（如 `hg`、`xhg`）与**分类筛选**（蔬菜 / 肉禽蛋 / 粮油调味 / 干货 / 半成品），列表同屏显示图片 / 名称 / 单位 / 规格 / 品牌 / 形态 / 采购量 / 备注；第 3 步总览补品牌·形态·单位·备注与将生成订单的日期，第 4 步列出将生成订单的日期与已删除日期。
- **退货 = 商品行售后（V2.0.21）**：退货不影响订单状态（订单始终「已完成」，已删除「退货中」状态）；行内「退货」= 实际验收量回显 + 退货量（≤实际验收量，必填）+ 退货原因（8 项枚举，必填）；发起后行操作变 `售后详情`；售后三态（待供应商确认 / 供应商已认可 / 供应商不认可）在 L2「售后状态」列展示；认可 → 回写该行实际验收量并标「有退货」，不认可 → 回显理由并可重新发起。
- **变更本期不做**：供应商改单 / 变更单 / 变更确认 / 版本号均已移出本期（见 PRD §9），L2 无「处理变更」、L3 无「变更记录」卡片、供应商模拟区无「修改订单」；订单发起后**不可撤回**。
- **订单可改（V2.0.41）**：只有「**待确认 + 直采下单**」的订单在 L2 行内提供 `修改订单`——抽屉可改收货人 / 收货地址，商品清单列序为 `序号 / 商品名称 / 单位 / 规格 / 品牌 / 单价 / 下单量 / 备注`，点 `+ 添加商品` 打开**与新建订单第 2 步同一套 picker**；保存后金额与时间轴同步，并通知供应商。采购计划 / 询价下单来源的订单没有该入口。
- **询价（V3.0 → V4.0 已下线）**：询价单 tab、询价单列表 / 详情、比价与定标、询价三步向导、选下单方式弹窗全部移除；`+ 新建订单` 直接进直采向导。
- **供应类型**：毛菜 / 净菜 / 半成品（多选 ≥1），口径来自租户端供应商管理档案；变更只影响新发起的询价，在途询价用快照。
- 推荐通过本地 HTTP 服务访问，避免浏览器对本地文件会话和跳转的限制。
