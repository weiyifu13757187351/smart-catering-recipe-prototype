| 项 | 内容 |
|---|---|

---

## 1. 定位

商户在采购前需要知道「我能从哪几家供应商下单、他们都供什么、出问题找谁」。这份名单完全由租户管理员配置，商户端只负责**看得见、看得清**，不参与任何维护动作。

因此本页面的三个设计约束：

1. **只读**：不出现新增、编辑、停用、解除合作等写操作。
2. **无组织切换器**：名单跟着「当前登录商户」走，不由组织范围决定，避免用户误以为切换组织会换供应商。
3. **不展示合作协议**：协议是租户与供应商之间的商务文件，商户端不暴露。

## 2. 可见性规则

| 规则 | 说明 |
|---|---|
| R1 | 供应商必须**已绑定到本商户**才出现（租户端「全部商户」或「指定商户」含本商户） |
| R2 | 供应商与租户的合作关系必须是**合作中**；租户端一旦「解除合作」，该供应商立即从本页消失 |
| R3 | 页面只展示本商户视角的数据，不出现「其他商户绑定了哪些供应商」之外的租户经营信息 |
| R4 | 商户端看到的联系人与联系方式，取该供应商在本租户合作关系上维护的值 |
| R5 | 更新供应商配置后，商户端下次进入页面即可看到最新名单（原型为内存数据） |

## 3. 列表页

**头部**：标题「供应商管理」+ 说明「本商户可选择的食材供应商，由租户管理员按商户绑定统一配置」+ 右上角「仅查看」标记。

**说明条**：一句话交代来源与出口——「由租户管理员在「组织经营 › 供应商管理」中配置并绑定到本商户，如需调整可选择的供应商范围，请联系租户管理员。」

**筛选**：供应商名称 / 统一社会信用代码关键词、供应类型（全部 / 毛菜 / 净菜 / 半成品）、查询、重置。

**列**：

| 列 | 内容 |
|---|---|
| 供应商信息 | 供应商名称 + 统一社会信用代码（小字） |
| 供应类型 | 毛菜 / 净菜 / 半成品，多选以标签展示 |
| 联系人及联系方式 | 联系人姓名 + 手机号（小字） |
| 供货商户范围 | 「全部商户」或「指定 N 家」（指定时用橙色标记，提示不是全租户通用） |
| 更新时间 | 该供应商最近一次被租户维护的日期 |
| 操作 | 查看详情 |

**空状态**：
- 有供应商但筛选无结果 →「没有符合条件的供应商，可调整关键词或供应类型后重试」
- 完全没有可用供应商 →「暂无可选择的供应商，请联系租户管理员在「组织经营 › 供应商管理」中为本商户绑定供应商」

## 4. 详情抽屉（点「查看详情」）

右侧 610px 抽屉，分四个区块，全部只读，底部固定「信息由租户管理员维护，商户端只读」+ 关闭。

### 4.1 基础信息
供应商名称、统一社会信用代码、联系人、联系方式、供应商地址。

> 联系人与联系方式是商户日常对接用到的信息，放在最外层，不需要再点开资质才能找到。

### 4.2 资质证照（用于食安索证索票）
营业执照、食品经营许可证、食品生产许可证三块并列，每块显示：证照名称、已传张数 / 上限、「证号 xxx」（无证号则不显示该行）、图片缩略占位（未上传显示「未上传」）。

下方提示：证照沿用供应商在平台的统一档案，由建档租户上传并维护。

> 这是商户端看供应商的核心诉求之一——索证索票。营业执照对应用户的统一社会信用代码，因此不再重复显示证号。

### 4.3 供货能力
按该供应商被租户配置的供应类型逐条展示，并附一句话解释（毛菜＝未加工蔬菜，商户自行分拣；净菜＝已分拣清洗，可直接使用；半成品＝切配腌制预制，简单加工即可）。

### 4.4 供货范围
- 全部商户 →「该供应商向租户下全部商户供货，本商户在范围内。」
- 指定商户 → 列出商户名称，**本商户所在的那一项高亮并标注「本商户」**
- 若本商户不在范围内（理论上不会出现，兜底）→ 橙色提示「本商户不在该供应商的供货范围内。」

## 5. 交互与边界

| 场景 | 行为 |
|---|---|
| 点击左侧其它菜单 | 本页自动收起，不残留 |
| 切回「供应商管理」 | 重新渲染列表，筛选条件重置为「全部」 |
| 抽屉关闭 | 点「关闭」、点遮罩、按 Esc 均可 |
| 抽屉内容超长 | 抽屉内部滚动，头部与底部固定 |
| 组织切换器 | 本页不挂载 |

## 6. 演示数据

| 供应商 | 供应类型 | 供货范围 | 说明 |
|---|---|---|---|
| 上海鲜配供应链有限公司 | 毛菜、半成品 | 全部商户 | 证照齐全，演示标准形态 |

供应商名称与统一社会信用代码与租户端原型保持同名同码，便于两端对照验收。租户端已置为「已解除」的供应商不会出现在本页。

## 7. 验收点

| # | 场景 | 预期 |
|---|---|---|
| AC01 | 进入页面 | 列表只出现绑定到本商户且合作中的供应商，无新增 / 编辑按钮，无组织切换器 |
| AC02 | 按供应类型「毛菜」筛选 | 只剩含毛菜的供应商 |
| AC03 | 关键词检索信用代码 | 命中唯一供应商 |
| AC04 | 筛选无结果 | 显示可调整条件的空状态 |
| AC05 | 点「查看详情」 | 四个区块齐全，证照张数与证号正确 |
| AC06 | 「指定商户」供应商详情 | 商户列表中本商户高亮并标「本商户」 |
| AC07 | 切换登录商户（阳光职工餐厅） | 「本商户」标记随之切换 |
| AC08 | 切到其它菜单再返回 | 本页正常收起与恢复，其它页面不受影响 |
