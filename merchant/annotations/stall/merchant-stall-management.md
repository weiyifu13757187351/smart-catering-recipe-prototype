# 商户端 · 档口管理业务标注

> 事实来源：《商户端 · 档口列表与组织/档口切换器 PRD》V1.0（2026-10-12，`商户端档口列表与组织切换器PRD.md`）。
> 本文只写原型看不出来、但实现或验收需要知道的规则。标注为「原型差异 / 口径冲突」的条目，是 PRD 已确认口径与原型当前实现不一致，需要研发或产品确认，**不要以原型为准**。

<!-- anno:start id=stall-list-rules -->
## 本页规则

### 页面定位与数据范围

- 入口：左侧一级「档口管理」→ 二级「档口列表」；面包屑「档口管理 / 档口列表」。
- 本页是档口主数据的**唯一维护端**。一个档口必属于且仅属于一个次级组织；一个次级组织可挂多个档口。
- **本页不挂「组织 / 档口切换器」**，直接用「所属组织 + 档口名称」查询本商户全量档口（PRD D5）。
- 数据范围 = 本商户全部次级组织下的档口。本期切换器与列表都**不做权限过滤**。

### 排序与分页

- 默认按**创建时间倒序**（新建档口出现在首行）。
- 列头**不提供排序**（PRD D8）。
- **不分页**：本期列表一次展示全部结果。

### 准入

- 本商户没有次级组织时，列表显示空态文案，「+ 新增档口」置灰（悬浮提示「请先创建次级组织」）。

### 删除后果（跨页）

- 档口删除后不可恢复；下游栏目在重新取数后不再显示该档口，**不保留历史快照**（PRD D3）。

### 原型说明

- 本页数据为内存演示数据，刷新页面恢复初始值；档口列表与「组织 / 档口切换器」、手机端共用同一份档口数据【原型】。

## 筛选行

| 控件 | 类型 | 规则 |
| --- | --- | --- |
| 所属组织 | 下拉 | 默认「全部组织」；选项 = 本商户全部次级组织 |
| 档口名称 | 输入 | 占位「档口名称」，最长 30 字，按**包含**匹配 |
| 查询 | 按钮 | 按「所属组织 + 档口名称」过滤并刷新列表 |
| 重置 | 按钮 | 清空两个条件并刷新列表 |

- 在档口名称输入框回车等同点「查询」。
- 组织下拉与名称一起在点「查询」（或回车）时才提交生效【原型】。
- 清空档口名称后**即时**刷新列表，不必再点查询【原型】。
- 筛选用的组织被删除后，该下拉回到「全部组织」。
<!-- anno:end id=stall-list-filter -->

<!-- anno:start id=stall-list-add -->
## 新增档口入口

- 本商户存在次级组织时，打开「新增档口」抽屉。
- 本商户没有次级组织时按钮置灰，悬浮提示「请先创建次级组织」，点击时提示「请先到「组织及成员」创建次级组织」【原型】。
- 新增与编辑共用同一套字段与校验规则。
<!-- anno:end id=stall-list-add -->

<!-- anno:start id=stall-list-table -->
## 列表字段

| 列 | 展示 | 业务说明 |
| --- | --- | --- |
| 所属组织 | 组织名称 | 组织已不存在时显示「—」 |
| 档口名称 | 加粗 | 最长 30 字；同一组织内不可重名，跨组织可重名 |
| 经营餐次 | 「餐次 起–止」标签 | 按餐次顺序排列（早餐→早点→午餐→午点→晚餐→夜宵） |
| 负责人及联系方式 | 姓名 + 手机号 | 无负责人时显示「—」 |
| 创建时间 | 创建人 · 创建时间 | 系统字段，不可编辑 |
| 操作 | 编辑、删除 | 见「行操作」 |

### 变动传导

- **次级组织被删除**：档口记录保留，本列显示「—」；此时编辑该档口，组织下拉里没有原组织，**保存前必须改挂到其它组织**。
- 本页写入的档口数据是「组织 / 档口切换器」与计划类栏目的只读取数来源；档口本身不在本页之外被修改。

| 场景 | 文案 | 新增按钮 |
| --- | --- | --- |
| 本商户无次级组织 | 当前商户还没有次级组织，请先到「组织及成员」创建次级组织 | 置灰，悬浮提示「请先创建次级组织」 |

| 查询无结果 | 没有匹配的档口，换个档口名称或组织再查 | 可用 |

## 行操作

- 「编辑」：打开「编辑档口」抽屉，标题为「编辑档口」，字段预填当前值。
- 「删除」：打开二次确认弹窗，见「删除档口确认」视图的规则。
- **不提供批量删除与导出**。

## 本页规则（新增 / 编辑档口抽屉）

### 形态

- 右侧抽屉，标题「新增档口」/「编辑档口」，底部「取消 / 保存」。
- 新增与编辑共用同一套字段与校验规则；编辑时预填当前值，保存即就地更新该档口。

### 保存后置

| 动作 | 结果 |
| --- | --- |
| 新增保存 | 生成档口记录（所属组织、名称、负责人、餐次与时间、各餐次人均、创建人与创建时间），提示「档口创建成功」，按创建时间倒序出现在首行 |
| 编辑保存 | 就地更新该档口，提示「档口信息已保存」，列表刷新 |
| 编辑中切换组织 | 负责人被清空，提示「已切换组织，请重新选择负责人」，需重新选择后才能保存 |
| 校验不通过 | 提示对应文案，**抽屉保持打开**，已填内容不丢失 |

### 原型差异（研发按 PRD 调整）

- **预计人均用餐量上限**：原型控件与提示为 9999，PRD 已确认上限为 **99999**（含校验文案 V11），需按 PRD 调整。来源：PRD D4 与 13.4 P1【待修正】。

## 字段与校验

| 字段 | 控件 | 必填 | 规则 |
| --- | --- | --- | --- |
| 组织选择 | 下拉 | 是 | 只列**次级组织**；默认「请选择次级组织」；编辑时预填原组织 |
| 档口名称 | 输入 | 是 | 最长 30 字；同一组织内不可重名，跨组织可重名 |
| 负责人及联系方式 | 下拉 | 是 | 候选 = 所选组织的成员；未选组织或无成员时禁用（见「负责人」） |
| 经营餐次 | 复选 | 是 | 至少 1 个；勾选后出现该餐次的时间与人均输入行，取消勾选即移除该行 |
| 各餐次营业时间 | 时间选择 | 是 | 一段起止，精确到分钟；结束时间须晚于开始时间 |
| 各餐次预计人均用餐量 | 数字 | 否 | 正整数，大于 0 且不超过 99999；单位「克 / 人」 |

### 校验清单（V1–V12）

| 编号 | 场景 | 提示文案 |
| --- | --- | --- |
| V1 | 未选择组织 | 请选择所属组织 |
| V2 | 档口名称为空 | 请输入档口名称 |
| V3 | 同一组织下已有同名档口 | 该组织下已存在同名档口 |
| V4 | 所属组织无成员 | 该组织暂无成员，请先到「组织及成员」添加后再选负责人 |
| V5 | 未选择负责人 | 请选择负责人 |
| V6 | 未勾选任何经营餐次 | 请至少选择 1 个经营餐次 |
| V7 | 某餐次未填时间 | 请填写{餐次}的营业开始 / 结束时间 |
| V8 | 结束时间早于或等于开始时间 | {餐次}的结束时间需晚于开始时间 |
| V9 | 两个餐次时间重叠 | {餐次A}与{餐次B}的营业时间重叠（{起}–{止}），请调整 |
| V10 | 人均用餐量非正整数 | {餐次}的预计人均用餐量需为大于 0 的数字 |
| V11 | 人均用餐量超上限 | {餐次}的预计人均用餐量不能超过 99999 克 |
| V12 | 档口名称超长 | 最长 30 字，超出不可输入 |

## 负责人

- 候选 = **该档口所属次级组织**的成员，单选 1 人（PRD D1），展示「姓名（成员类型）+ 手机号」。
- 未选择组织时下拉禁用，显示「请先选择组织」。
- 所选组织没有成员时下拉禁用，显示「该组织暂无成员」，并在字段下提示「该组织暂无成员，请先到「组织及成员」添加后再选负责人」。
- 编辑态切换组织会清空已选负责人，需重新选择后才能保存。

> **口径冲突（需产品确认）**：PRD D1 明确负责人候选**不向下级组织取人**；原型当前取的是所选组织**及其下级组织**的成员。若以 PRD 为准，需收窄候选范围。
<!-- anno:end id=stall-editor-owner -->

<!-- anno:start id=stall-editor-meals -->
## 经营餐次 / 营业时间 / 预计人均用餐量

- 餐次集合固定 6 个：早餐、早点、午餐、午点、晚餐、夜宵；至少勾选 1 个。
- **每个餐次只允许一段营业时间**，不支持多时段（PRD D2）。
- 同一档口内各餐次营业时间**不可重叠**；**首尾相接可以**（如早餐 09:00 结束、早点 09:00 开始）。
- 校验不通过时提示并标红冲突的餐次行，抽屉不关闭。
- 预计人均用餐量：非必填；**留空即视为不设置，不做兜底填报**；填写时必须为大于 0 的整数。
- 该值供下游栏目按该档口该餐次取默认值时使用，**具体消费规则待对应栏目评审**（PRD 7.4）。

### 原型差异

- 原型控件上限为 9999 且提示「不能超过 9999 克」，PRD 已确认上限为 **99999**（PRD D4 / P1【待修正】）。
- 原型抽屉常驻提示写到「填写后，排餐计划里该餐次的人均用餐量默认引用此值」；PRD 7.4 的口径是「供下游栏目取默认值，消费规则待对应栏目评审」，**文案口径以后者为准**。
<!-- anno:end id=stall-editor-meals -->

<!-- anno:start id=stall-editor-actions -->
## 取消 / 保存

- 「保存」：按 V1–V12 顺序校验，全部通过才写入；校验不通过时提示对应文案并保持抽屉打开。
- 「取消」：直接关闭抽屉，不保存本次改动。
- 点击抽屉遮罩空白处等同取消【原型】；原型未做「有未保存内容时二次确认」。
<!-- anno:end id=stall-editor-actions -->

<!-- anno:start id=stall-delete-rules -->
## 本页规则（删除档口确认）

- 入口：列表行内「删除」。
- 二次确认文案：「确认删除档口「{档口名称}」吗？删除后不可恢复。」
- 确认后：提示「档口已删除」，列表刷新，记录**不可恢复**。
- 下游影响：消费档口的栏目在重新取数后**不再显示**该档口，**不做历史快照**（PRD D3）。
- 档口不提供批量删除与导出。
<!-- anno:end id=stall-delete-rules -->

<!-- anno:start id=stall-data-downstream -->
## 档口主数据与下游消费（跨页）

- 档口只有**一个维护端**（档口列表）；「组织 / 档口切换器」只读，不修改档口数据。
- 档口被删除：列表与切换器的档口下拉都不再出现；已消费该档口的栏目在重新取数后不再显示，不留历史快照（PRD D3）。
- 次级组织被删除：档口记录保留，「所属组织」显示「—」，保存前需改挂到其它组织。
- 组织下没有成员：新增 / 编辑时负责人下拉禁用，需先到「组织及成员」添加成员。
- 各餐次「预计人均用餐量」供下游栏目按该档口该餐次取默认值；消费规则待对应栏目评审。
- 本期不含：档口启用 / 停用状态、档口编码、档口下级层级、档口自定义排序、经营数据统计（PRD 3.3）。
<!-- anno:end id=stall-data-downstream -->
