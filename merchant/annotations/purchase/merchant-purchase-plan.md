# 商户端 · 采购计划业务标注

> 事实来源：《商户端采购计划 PRD V3.0》（`商户端采购计划PRD-V3.0.md`，PC 端口径，原型为 2026-10-22 采购计划 V2）。
> 本文只写原型看不出来、但实现或验收需要知道的规则。标「原型差异」的条目是 PRD 口径与原型现状不一致，**不要以原型为准**；标「待确认」的条目 PRD 未定，不要按惯例补齐。
> 采购计划只挂在**档口**上：组织层不是一份计划，而是各档口的入口。

<!-- anno:start id=pp-overview-rules -->
## 本页规则

### 页面定位

- 入口：左侧「计划管理」→「采购计划」；面包屑「计划管理 / 采购计划」。
- 落地页是**组织层档口总览**：没选到具体档口时只能看卡片，**没有新建按钮**；点卡片或切换器选档口才进列表。
- 计划归属：该组织下**每个档口各自**的计划，统计不跨档口合并。

### 数据来源

- 用料清单由**已保存的排餐计划 × 菜谱 BOM** 派生；未保存的排餐改动下游看不见。
- 商品、规格、下单单位取自商品中心；供应商取自供应商管理的启用清单。

### 范围切换

- 切换器全局共享：本页换档口，排餐计划、生产计划的当前范围一起变。
- 在档口层切换组织 → **回到新组织的总览**，不自动跳第一个档口（原型差异：原型会留在原视图）。
- 组织下没有档口时：下拉禁用并提示「该组织暂无档口」，总览显示「暂无档口，请先创建档口」。

## 档口卡片

| 卡片内容 | 口径 |
| --- | --- |
| 档口名称 | 档口主数据，本页只读 |
| 负责人 | `姓名 · 电话`；未指定时显示「未指定负责人」 |
| 营业餐次 | 该档口配置的餐次与时间（采购计划恒取全部餐次） |
| 底部提示行 | 该档口**全部**计划数 N 与询价在途数 M |

### 底部提示行文案

| 条件 | 文案 |
| --- | --- |
| N = 0 | `暂无采购计划` |
| N > 0 且 M = 0 | `N 份采购计划` |
| N > 0 且 M > 0 | `N 份采购计划 · M 份询价在途` |

- 例：14 份计划、8 份在途 → `14 份采购计划 · 8 份询价在途`。
- 「在途」= 该档口最新询价单状态为**询价中或已截止**；**已定标、已流标都不算在途**。
- 卡片统计按档口分别计算，不跨档口合并。

## 本页规则

### 一档口多计划

- 计划 = 「档口 × 需求周期区间」；同一档口的多份计划**可以区间重叠，互不覆盖**：各自独立询价、独立定标，重叠天数不合并、不作废已定标结果。
- 排序：更新时间倒序，其次起始日倒序。

### 状态与删除（重点）

- 状态由**最新询价单**派生：无询价单=草稿 / 询价中 / 已截止 / 已定标 / 已流标（后两个为终态）。
- **已定标** = 定标提交时至少 1 个商品成交；**已流标** = 提交时 0 个商品成交【本期新增】。
- **只有草稿有删除入口**；询价中、已截止、已定标、已流标的行不显示「删除」，也没有"点了才发现不能删"的提示。
- 删除只删该计划与其按天填量、材料行、映射覆盖；**其他同期计划编号不变**，不重排、不回收空号。
- 删除后新建同区间计划仍取「现有最大序号 + 1」，不复用被删掉的号。

### 空态

- `暂无采购计划` + 引导「点击右上角『新建采购计划』…」。

## 新建采购计划

- 仅**档口层**列表有这个按钮；组织层总览没有。
- 点开是抽屉：需求起始日、结束日，默认**本周一 ~ 本周日**。
- 抽屉里必须做**范围预览**（区间内命中几天、无排餐几天、菜品几道）——原型没有（原型差异，本期新增）。
- 创建成功后直接进该计划详情的「商品映射」页签。

- 「同期」= 同一档口 **起止日完全相同**；只是区间有交集**不算**同期，也不显示标签。

- 标签只在同期第 2 份起显示，第 1 份不显示。

## 本页规则

### 这一页回答什么

- 材料层：**一行 = 一个用料**，只决定「这个用料买哪个商品」，不填量、不管哪天。
- 行类型三种：标准食材行（菜谱用料未直挂）、菜谱直挂行（已绑 SKU）、手工添加行（采购明细里加的）。

### 候选商品（本页最重要）

- 标准食材行的候选只能是：本组织商品中心中**状态=已发布**，且该商品的「关联标准食材」**包含这个食材**。
- 毛菜关联 1 个食材、净菜可关联多个、**半成品不关联** → 半成品永远不会出现在标准食材行候选里。
- 草稿、已下架商品不可选。
- **找不到关联商品时不得降级为全部商品**（原型差异：原型会退化为全量商品）。表现为抽屉只给说明 + 取消，并阻断发起询价。
- 手工添加行可选全部已发布商品；菜谱直挂行不可更换。

### 本期新增 / 原型差异

- **整段忽略**（新增按钮）：本计划所有日期都不采购该用料。原型商品映射页只有「选择/更换」「依据」，**没有任何忽略入口**，忽略目前只有采购明细的「忽略（仅当天）」。
- **重新生成**（新增按钮）：草稿态按当前已保存排餐重算材料行，保留已选商品、整段忽略、按天覆盖与按天填量；排餐无变化时提示「排餐没有变化，无需重新生成」。
- 锁定后（已发起询价、已定标或已流标）整页只读，隐藏所有编辑按钮，只保留「依据」与重新查看。
- **演示数据必须删除**：原型内置的演示用料行、「模拟供应商回价」按钮、自动补演示排餐的行为都不得进正式版（原型差异）。
<!-- anno:end id=pp-mapping-rules -->

## 页头与统计

- 左：`‹ 返回列表`、标题 `起始日 ~ 结束日` + 状态标签 + （同期第 2 份起）「同期第 X 份」、副标题 `N 天 · 档口：名 · 全部餐次`。
- 统计条 `N 项用料 · M 个商品 · 已映射 x/N`：N = 未被整段忽略的材料行数；M = 最终会用到的 SKU 去重数（只算当天真的用到且没被忽略的行）；x = 其中已映射的行数。
- 右：`发起询价`；锁定时禁用，原因看锁定提示条。
- 锁定提示条：`询价单「INQ…」已发起，本页锁定为只读。`／`本计划已定标「INQ…」，本页锁定为只读（终态）。`／`本计划已流标「INQ…」，本页锁定为只读（终态）。`

## 三个页签的分工

| 页签 | 回答 | 锁定规则 |
| --- | --- | --- |
| 商品映射 | 这个用料买哪个商品（作用于所有日期） | 与采购明细一起锁，整份计划锁定 |
| 采购明细 | 哪天买、买多少（可按天换商品） | 同上 |

- 未发起询价时，第三个页签标题显示「询价单（未发起）」。

## 本页规则

- 两步：①按名称/加工形态/分类筛商品 → ②点 SKU 卡片**即时生效**，没有「确定」按钮。

- 当前在用的 SKU 标「当前」。
- 候选为空：只给一句说明与「取消」，不允许"放开全部商品"兜底。

## 用料依据

- 只读：列 日期、星期、餐次、菜品、锅数、用量（克）、当日合计。
- 用量口径：投料量（克）× 锅数；**只取「烹饪投料（计入）」**，过程用料（不计入）不进采购。
- 单位恒为克，系统**不做克 → 箱/袋换算**：数量由采购员按下单单位自己判断。
- 从采购明细某天点「依据」时，该天所在行高亮，便于核对。

## 本页规则

### 填量的硬规则

- **每天、每条已映射商品的行都必须填**预计采购量，且 > 0，最多 2 位小数；留空等于没填，会被拦在发起询价之前。
- 不买的写法是「忽略（仅当天）」，**不要留空**。
- 数量 = 该 SKU 的**下单单位数量**（箱/袋/桶/吨）；克数只作参考显示，系统不换算。

### 日期 tab

- 只有**有用料的天**才出现；日期升序；默认选今天（不在区间内则选第一天）。
- 日期 tab 右上角红色数字 = 当天「已映射商品且预计采购量 ≤ 0」的行数，防止在 10-20 填完就以为全部完成。
- 表尾 `已填 X/Y 项`：Y = 当天已映射商品的行数，X = 其中填了量的行数；未填满时数字变橙。

### 当天覆盖

- 当天换商品只改**当天**，其他天仍用行上的商品；标「当日指定」，可「恢复默认」。
- 菜谱直挂行的商品由菜谱绑定，采购侧不可更换，只能整段忽略或当天忽略。
- 当天忽略移入下方「当日已忽略」区（显示「不计入」），可「恢复当天采购」，不影响其他天。
- 「添加商品」加的手工行只存在于当天，无克数依据，加完必须填量。
<!-- anno:end id=pp-days-rules -->

## 当日已忽略

- 只影响**当前这一天**，其他日期照常采购。
- 每行显示「不计入」，可「恢复当天采购」；锁定态显示「只读」。
- 当天被忽略完时，该天在上方表格里显示空态提示，而不是整天消失。

## 添加手工商品

- 可选范围：本组织商品中心中**状态=已发布**的全部商品（不受食材关联限制，因为没有食材语境）。
- 只加在**当前这一天**，计入「明细行」数量与当日合计，但没有克数依据。
- 加完必须填预计采购量，否则发起询价时会被拦下。
- 手工行可以「删除」；删除只影响该行与其按天填量。

<!-- anno:start id=pp-inquiry-rules -->
## 本页规则

### 状态机

- 询价单状态：草稿（本期不产生）→ 询价中 → 已截止 → 已定标／已流标。
- **已定标** = 至少 1 个商品选定供应商；**已流标** = 提交定标时 0 个商品成交，本轮询价作废【本期新增】。
- **发起后不可撤回**：询价中、已截止、已定标、已流标都不能撤回，截止时间不能延长，超时未报价不接受补报。
- 「已截止」与「超时未报价」必须在**到达截止时间时自动生效**，不能等用户打开页面才变；到点判定以服务端时间为准（原型差异：原型是打开页面时才算）。
- 一份计划同一时刻只能有 **1 份在途询价单**；已有则阻断发起，提示 `该计划已有询价单，不能再发起`。
- 要重来只能另建一份**同期**采购计划（同一档口 + 完全相同的起止日）。

### 快照

- 发起时冻结：受邀供应商、每个 SKU 的合计数量、按天需求、商品名/形态/规格/下单单位。
- 之后计划再怎么改都不影响已发出的询价单；商品下架也不影响。

### 询价数量

- 该 SKU 在本计划内**所有天、所有映射到它的行**的填量之和，2 位小数，单位 = 下单单位。
- 不是克数、不做换算。
<!-- anno:end id=pp-inquiry-rules -->

<!-- anno:start id=pp-inquiry-head -->
## 询价单页头与操作

| 元素 | 口径 |
| --- | --- |
| 单号 | `INQ + yyyyMMdd + 2 位流水`；正式版由后端生成并保证唯一，前端只展示 |
| 状态标签 | 询价中 / 已截止 / 已定标 / 已流标 |
| 发起 / 截止 | 发起时间、报价截止时间（截止时间发起后不可改） |
| 剩余时长 | 仅询价中显示「剩余 X 小时 Y 分」；到点显示「已到截止时间」；其他状态显示 `—` |

- 按钮：`报价比较`（有单即可）、`定标`（询价中/已截止即可点，**不要求有报价**；0 家报价也能提交，提交即流标）、`模拟供应商回价`（**仅原型演示，正式版删除**）。

## 本页规则

### 两类校验的分工

- **A 类（状态类，决定「确认发起」是否可用）**，不通过就禁用并列出原因：

| # | 校验 | 提示 |
| --- | --- | --- |
| A1 | 至少一条「至少有一天要采购」的材料行（整段忽略/全忽略的不算） | `没有可采购的用料，无法发起询价` |
| A2 | 所有生效的标准食材行都已映射商品 | `还有 N 项标准食材未选择商品：…` |
| A3 | 每天每条已映射商品的行都填了量（> 0） | `预计采购量为必填：还有 N 项没填（…），涉及 M 天` |
| A4 | 至少有一个可询价的 SKU | `没有任何可询价的商品` |

- **B 类（抽屉输入类，提交那一刻校验，不参与按钮置灰）**：截止时间必填、≥ 当前时间 + 1 小时（默认 +24 小时）、至少选 1 家供应商。
- B 类不能并进按钮可用性：否则会出现勾了供应商按钮状态不更新的死按钮。

### 提交结果

- 幂等：重复点击/并发提交只成功一次。
- 成功后：状态 → 询价中；两个页签变只读；删除入口消失；自动跳到「询价单」页签；提示 `询价单 INQ… 已发起，已通知 N 家供应商`。

<!-- anno:start id=pp-compare-rules -->
## 本页规则

### 比价只做一件事：摊开

- 行 = 询价单商品行；列 = 本单受邀供应商（表头带应答状态与「已报 M/N 项」）。
- 单元格 = 该供应商对该商品的报价；无报价显示 `-`，**不补、不推算、不填 0**。
- 每行最低价绿色高亮；同价并列全部高亮。
- **不计算总价、不排序、不给推荐、不自动勾选定标**。
- 不做任何单位换算：同一行用同一个 SKU 的下单单位。
- 不展示预报价/历史价，价格只看本轮实际回价。

### 入口

- 询价单页签「报价比较」→ 整单矩阵。
- 明细行「N 家已报」→ 只看这一行；该行一家都没报时单独提示。

### 0 报价

- 整单：`本轮所有供应商都没有提交报价（超时未报价）。需要重来时请另建一份同期采购计划重新发起。`（不是"不能定标"：仍可提交定标，提交即流标）
- 说明文案：绿色高亮 = 本轮最低价，仅展示、不做推荐，定标请在「定标」里逐个商品选择。
<!-- anno:end id=pp-compare-rules -->

<!-- anno:start id=pp-line-quote-body -->
## 单行报价明细

- 与整单比价同一个矩阵，只摊开点进来的那一行。
- 副标题带上该行商品名、询价数量与按天需求，便于核对报价对应的是哪批货。
- 该行**没有任何报价**时提示：`这一行目前没有任何报价。超时未报价的供应商不会补报；需要重来时请另建一份同期采购计划重新发起。`

<!-- anno:start id=pp-award-rules -->
## 本页规则

### 定标粒度与可选项

- **按商品逐个定标**，一个商品定一家供应商；下拉里只出现**对该商品报过价**的供应商（首项「请选择供应商」）。
- 无供应商报价的商品沉到「无供应商报价」分组，整行不可选，显示「无可选供应商」。
- 参考单价 = 所选供应商对该商品的报价；预估总价 = 参考单价 × 采购量（未选显示 `-`）。
- 「一键选择价格最低的供应商」：每个有报价的商品自动选最低价（并列取列表第一家），之后可再逐个调整；「清空供应商」回到未选。
- **未选 = 不采购**：一个都不选也能提交，结果 = 0 个商品成交；提交校验只在点「确认定标」时求值。

### 二次确认（必须做）

提交前按两种情况提示：无报价商品 N 个、有报价但未选供应商 M 个；都没有则直接提交、不弹窗。

| 情况 | 标题 | 正文要点 |
| --- | --- | --- |
| 两者都有且至少选了 1 个 | 定标结果需要你确认 | N 个无报价、M 个未选，这些商品均不采购，其他商品锁定定标结果（本期不生成订单） |
| 只有无报价 | 同上 | N 个商品无供应商报价，无法采购 |
| 只有未选 | 同上 | M 个商品未选择供应商，视为不采购 |
| 一个都没选 | 本次定标没有可采购的商品 | 本轮没有任何商品可以定标，**提交后按流标处理**（只存在一种情况时前半句只写那一种） |

- 按钮：`我再看看` / `确认`。
- **文案口径**：不写「生成正式订单」，统一写「锁定定标结果（本期不生成订单）」；0 成交那条写「提交后将会按流标处理」。

### 结果：已定标 / 已流标【本期新增】

- **至少 1 个商品成交** → 记录每个商品的定标供应商，状态 → 已定标；计划派生状态 → 已定标（终态）。
- **0 个商品成交** → 状态 → 已流标，本轮询价作废（终态）；提示 `本轮无成交商品，询价单 INQ… 已流标（本期不生成订单）`。
- 两种都是终态：不可修改、不可取消、不可再发起询价、不能删除计划；已定标时明细行显示「已定标 · 供应商名」，已流标时不显示该标签；比价仍可看。
- **本期都不生成采购订单、不推送供应商**。
<!-- anno:end id=pp-award-rules -->

<!-- anno:start id=pp-award-body -->
## 定标抽屉

| 区块 | 口径 |
| --- | --- |
| 顶部条 | 一键最低价、清空供应商、右侧 `已选 X/Y 个商品 · 预估总价 ¥Z` |
| 表格列 | 商品（+形态）、规格、下单单位、采购量、参考单价、预估总价、供应商下拉 |
| 行分组 | 有报价的在上可选；`无供应商报价` 分组在下，整行不可选 |

- 采购量取询价单快照里的数量（下单单位），不是克数。
- 一个都不选也能提交，提交后按流标处理（状态变「已流标」），不是"按钮禁用"。
<!-- anno:end id=pp-award-body -->

<!-- anno:start id=pp-award-confirm -->
## 定标确认弹窗

- 只在存在「无报价商品」或「未选供应商」时出现；两种情况都没有则直接提交。
- 正文必须写清「这些商品不采购」+「其他商品锁定定标结果（本期不生成订单）」。
- **0 个商品选中**时标题是「本次定标没有可采购的商品」，正文末句为「提交后将会按流标处理」——确认后计划进「已流标」终态【本期新增】。
- 「我再看看」= 回到定标抽屉继续调整；「确认」= 提交并进入终态（已定标或已流标）。
- 弹窗本身不产生任何订单，本期也不推送供应商。
<!-- anno:end id=pp-award-confirm -->

<!-- anno:start id=pp-overlap -->
## 交集提醒

- 触发：新建时该档口已有**起止日完全相同**或**区间有交集**的计划。
- **只提醒、不阻断**：确认后照样创建，编号按同期规则顺延。
- 正文写清：`档口名 在 起始 ~ 结束 这段需求周期已有 N 份采购计划（其中 M 份区间完全相同）`；只是交集时写「（区间存在交集）」。
- 列表每项：区间、天数、状态、询价单号（无则「未发起询价」）。
- 说明固定：多份计划互不覆盖、各自独立询价与定标，重叠天数不会自动合并或作废已定标结果。
- 按钮：`否，先看看已有的` / `是，仍要新建`。
- 其它档口同区间的计划不算冲突。
<!-- anno:end id=pp-overlap -->
