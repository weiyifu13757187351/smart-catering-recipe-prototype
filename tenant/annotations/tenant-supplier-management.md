## 供应商管理本页规则

> 来源：`../租户端供应商管理PRD.md#6. 列表页`、`#2. 角色与权限`

### 数据范围
- 列表展示**本租户全部合作关系**（含已解除），不是平台全部供应商；他租户的合作范围不可见。
- 同一供应商可被多个租户分别建档/合作，本页每行 = 本租户与一个供应商的一条合作关系。

### 账号归属决定可操作项
| 账号归属 | 判定来源 | 可操作 |
| --- | --- | --- |
| 本租户开户 | 账号由本租户创建 | 重置密码、编辑本租户侧信息、解除/继续合作 |
| 沿用他租户账号 | 账号已由他租户开通 | **不可重置密码**（按钮置灰）；不可新建账号；主体信息只读 |

### 三个入口的语义差异
| 入口 | 命中的档案状态 | 结果 |
| --- | --- | --- |
| 新建供应商 | 平台无此档案 | 建档 + 同时开通超管账号 |
| 建立合作 | 平台有档案、本租户未合作 | 沿用原档案，**不开户**，只建立本租户的合作关系 |
| 重复创建 | 本租户已合作 | 阻断，提示「该供应商已存在于本租户，请勿重复创建」 |

### 列表口径
- 原型为前端筛选 + 假分页（「共 N 条」为当前数据量）；真实分页与排序**待确认**。
- 无搜索/筛选结果时显示空行「没有符合条件的供应商」。

## 顶部说明条：三条全局前提

> 来源：`../租户端供应商管理PRD.md#1. 背景与目标`、`#5. 关键规则 R1`、`#5. 关键规则 R12`

- **档案全局唯一**：身份键 = 统一社会信用代码；供应商档案是平台级资产，只有**建档租户**能维护主体信息。
- **账号归首个开户租户**：一个供应商只有一个超管账号，其他租户只能沿用与回显，不能重复开户。
- **解除合作只影响本租户**：不修改供应商档案、不启停账号、不影响其他租户的合作与下单；该供应商**已产生的询价单与采购订单继续履行**。
- 已定口径：**不存在「使用有效期」**。账号开通后长期有效，到期/续期相关的判断一律不出现。

## 筛选与搜索语义

> 来源：`../租户端供应商管理PRD.md#6. 列表页`

| 项 | 可选项 | 语义 |
| --- | --- | --- |
| 搜索框 | — | 对「供应商名称 + 统一社会信用代码 + 超管账号」做不区分大小写的包含匹配 |
| 供应类型 | 全部 / 毛菜 / 净菜 / 半成品 | 命中该供应商**任一**供应类型即列出 |
| 账号归属 | 全部 / 本租户开户 / 沿用他租户账号 | 按账号的开户租户精确过滤 |
| 合作状态 | 全部 / 合作中 / 已解除 | 已解除的行保留在列表，可继续合作恢复 |

- 条件之间为 **AND**；值变化即时生效，原型为逐行显隐、不重新取数。

## 列口径与行操作后果

> 来源：`../租户端供应商管理PRD.md#6. 列表页`、`#9. 状态机`、`#5. 关键规则 R11`、`#5. 关键规则 R12`

### 列
| 列 | 口径 |
| --- | --- |
| 供应商信息 | 名称（主）+ 统一社会信用代码（副）；**不显示供应商编码**，也不显示商户副标题 |
| 供应类型 | 该合作关系下选择的类型标签，多选 |
| 合作商户 | 家数 + 「全部商户 / 指定商户」；全部商户 = 本租户商户总数 |
| 超管账号 | 账号 + 「本租户开通 / XX租户开通」，颜色区分归属 |
| 状态 | 合作中 / 已解除 两态，无第三态 |
| 创建时间 / 更新时间 | 精确到分（`YYYY-MM-DD HH:mm`），列表用「日期加粗 + 时分弱化」两行展示；创建时间 = 本租户与该供应商建立合作关系的时间，更新时间 = 最近一次编辑 / 重置密码 / 解除或继续合作的时间；**系统自动记录，不记录操作人员**，任何位置都不展示操作人 |

### 行操作
| 动作 | 条件与结果 |
| --- | --- |
| 详情 | 只读查看，任何归属都可打开 |
| 编辑 | 本租户侧字段可改；他租户建档的主体信息只读（见详情可编辑性矩阵） |
| 重置密码 | 仅本租户开通的账号可重置，重置为 `Slw@000000`；他租户开通时按钮置灰并说明开通租户 |
| 解除合作 | 状态变「已解除」：本租户商户不可再**新增**选择该供应商；历史单据照常履行；不影响其他租户 |
| 继续合作 | 状态回「合作中」，本租户商户恢复可选；**无任何有效期门槛** |

- 状态只有两态，解除后可随时恢复，不设审批、不做二次确认以外的额外校验。

## 新建 / 编辑 / 建立合作抽屉本页规则

> 来源：`../租户端供应商管理PRD.md#7. 新建供应商`、`#5. 关键规则 R1`、`#5. 关键规则 R2`、`#5. 关键规则 R3`

### 信用代码「核验」的三条分支
| 核验结果 | 抽屉表现 |
| --- | --- |
| 平台无此档案 | 正常填写全部字段，标题「新建供应商」，主按钮「确认创建」 |
| 命中本租户 | 阻断：「该供应商已存在于本租户，请勿重复创建」 |
| 命中他租户 | 进入「建立合作」模式：标题「建立供应商合作」、主按钮「确认建立合作」；名称/地址/许可证/证照/账号**只读带入**；联系人、联系方式默认带出但**可改**；合作协议为空需本租户上传；供应类型与供货商户范围独立设置 |

### 提交校验（逐项阻断，首条 toast，底部汇总最多 3 条）
| 项 | 规则 |
| --- | --- |
| 供应商名称 | 必填（建立合作模式下沿用原档案，不校验） |
| 统一社会信用代码 | 必填；18 位 `0-9A-Z`；本租户内不可重复 |
| 联系人 / 联系方式 | 均必填；手机号 `1[3-9]` 开头 11 位 |
| 超管账号 | 平台无档案时必填且不可与其他供应商账号重复；建立合作模式不可填 |
| 营业执照 | 至少 1 张（建立合作模式沿用原档案，不校验） |
| 供应类型 | 至少选 1 个 |
| 供货商户范围 | 选「指定商户」时至少绑定 1 家 |

### 字段编辑权（全局档案 vs 租户私有）
- **只有建档租户**能改：名称、信用代码、地址、食品经营/生产许可证号、三类证照；改完**实时同步**给所有合作该供应商的租户。
- **各租户独立**：联系人、联系方式、合作协议、供应类型、供货商户范围。
- 账号与默认密码在编辑态不可改；**抽屉里没有「使用有效期」字段**（已取消）。

## 资质证照

> 来源：`../租户端供应商管理PRD.md#5. 关键规则 R5`、`R6`、`R7`

| 证照 | 必填 | 数量上限 | 归属与说明 |
| --- | --- | --- | --- |
| 营业执照 | ✅ | 2 张 | 全局档案，建档租户维护，跨租户同步 |
| 食品经营许可证 | ✕ | 2 张 | 需先填许可证号才可上传；全局档案 |
| 食品生产许可证 | ✕ | 2 张 | 同上 |
| 合作协议 | ✕ | 10 张 | **本租户独立签署**，不沿用其他租户，也不跨租户可见 |

- 上传交互：支持多选与逐张删除，实时计数 `n/max`，满额后上传入口禁用。
- 合作协议**不留历史版本**：替换或删除即生效，不保留旧协议记录。

## 超管账号

> 来源：`../租户端供应商管理PRD.md#5. 关键规则 R2`、`R10`、`R11`

- 一个供应商**只有一个**超管账号，平台唯一；该账号用于登录供应商系统。
- 账号由**首个开户租户**创建；后续租户建档时若平台已有账号：账号栏只读回显，并提示「该供应商账号已存在（账号 xxx），请使用该账号登录供应商系统」，**不提供开户入口**。
- 账号创建后**不可修改**；如需变更需联系平台（原型写死该提示）。
- 默认密码固定 `Slw@000000`，只读展示，**首次登录强制修改**。
- **不设有效期**：账号开通后长期有效，没有到期、续期、到期停用等逻辑。
- 重置密码：仅账号归属租户可操作，重置为默认密码并记录最近重置时间；重置后首次登录须改密。

## 供应类型

> 来源：`../租户端供应商管理PRD.md#5. 关键规则 R8`

- 三个类型：**毛菜**（未加工蔬菜，商户自行分拣）、**净菜**（已分拣清洗）、**半成品**（切配腌制预制）。
- **至少选 1 个**，多选；不选则阻断提交。
- 业务作用：决定**商户端采购时**能按哪些形态选到该供应商；类型不覆盖的形态，商户端不可选。
- 变更只影响**新发起**的采购，在途单据不受影响。
- 建档时提示该供应商在平台已有的类型（跨租户可见），本租户可独立调整。
<!-- anno:end id=sup-types -->

## 商户供货范围

> 来源：`../租户端供应商管理PRD.md#5. 关键规则 R9`、`#5. 关键规则 R12`

- 两种模式：**全部商户**（本租户下全部商户可选，默认）/ **指定商户**（仅勾选的商户可选）。
- 选「指定商户」时**至少绑定 1 家**，否则阻断提交。
- 未绑定范围内的商户，在采购业务中**选不到**该供应商；解绑只影响**新增**采购，不影响历史订单。
- 范围是**租户私有**的，其他租户看不到本租户的范围配置。
- 解除合作后，本租户商户端不再可选该供应商，但已产生的询价单/采购订单继续履行。

| 分区 / 字段 | 建档租户 | 非建档租户 |

- 详情是**只读视图**：除上述可编辑字段外，不提供任何写操作；档案更新日期取自最近一次保存。

## 详情 · 超管账号卡

> 来源：`../租户端供应商管理PRD.md#5. 关键规则 R2`、`R10`、`R11`

- 四个展示项：超管账号、归属租户、开户时间、最近重置密码；**没有使用有效期**。
- 「归属租户」是判断能否重置密码的唯一依据：非本租户开户时，详情页的重置按钮禁用。
- 他租户开户时页面显示提示：账号已存在、请使用该账号登录供应商系统、本租户不可创建与重置。
- 供应商账号到期相关逻辑已取消，此处不再出现「剩余 N 天」「即将到期」等表述。

## 详情 · 商户供货范围

> 来源：`../租户端供应商管理PRD.md#5. 关键规则 R9`、`#9. 状态机`

- 全部商户模式显示商户总数；指定商户模式逐个列出已绑定商户。
- 该范围只对本租户生效，是商户端能否选到该供应商的**唯一依据**（叠加供应类型匹配）。
- 合作关系为「已解除」时，详情顶部给出提示；恢复入口在列表的「继续合作」。

## 跨页共享规则与边界

> 来源：`../租户端供应商管理PRD.md#2. 角色与权限`、`#10. 跨租户口径`、`#13. 待确认`、`附录A`

### 一句话口径
**档案有主人（建档租户），合作各管各的。** 主体信息与账号跨租户共享，联系人/协议/类型/商户范围按租户独立。

### 租户端 ↔ 商户端
| 维度 | 租户端（本页） | 商户端 |
| --- | --- | --- |
| 数据来源 | 建档 + 维护合作关系 | 只读本租户「合作中」的供应商 |
| 可见范围 | 本租户全部合作关系 | 供货商户范围包含自己 + 供应类型匹配 |
| 可操作性 | 建档、开户、改档案、解除/继续合作 | 仅查看详情，无写操作 |
| 已解除 | 列表保留并可恢复 | 直接不可见 |

- 商户端详情**不出现**「超管账号」「合作协议」等租户私有信息。
