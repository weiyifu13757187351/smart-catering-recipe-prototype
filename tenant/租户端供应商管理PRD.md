## 1. 背景与目标

**前提（一句话）**：供应商档案是**平台级资产**，超管账号**平台唯一**；租户与供应商之间是**合作关系**，一个租户一份。

| # | 目标 |
| --- | --- |
| G1 | 供应商档案一次建档、多租户复用，避免每家租户重复填同一套资质 |
| G2 | 供应商账号开一次、多租户共用，避免一个供应商出现多个登录入口 |
| G3 | 每个租户独立维护自己的合作范围（联系人、合作协议、供应类型、供货商户） |

## 2. 角色与权限

| 角色 | 能做 | 不能做 |
| --- | --- | --- |
| 租户管理员 | 新建供应商（平台无此档案时）、为自己建档的供应商开通超管账号、修改**自己建档**的主体信息、维护本租户的联系人/联系方式/合作协议/供应类型/供货商户、重置超管密码、解除合作、继续合作 | 改他租户建档的主体信息与证照；给已有账号的供应商再开账号；删除供应商档案或账号；查看其他租户的供货商户范围 |

> 口径：**档案有主人（建档租户），合作各管各的。**

## 3. 名词口径

| 名词 | 定义 |
| --- | --- |
| 供应商档案 | 全局唯一记录：名称、统一社会信用代码、地址、食品经营/生产许可证号、三类证照。**唯一维护方 = 建档租户** |
| 合作关系 | 租户 × 供应商的关联：联系人、联系方式、合作协议、供应类型、供货商户范围、合作状态 |
| 超管账号 | 供应商登录供应商系统的唯一账号，平台唯一，一个供应商只有一个 |
| 供应类型 | 毛菜 / 净菜 / 半成品，多选 ≥1，决定商户端采购时哪些形态能选到该供应商 |
| 供货商户范围 | 本租户下允许采购该供应商的商户集合，默认全部 |

## 4. 功能清单

| 模块 | 功能 | 触发条件 |
| --- | --- | --- |
| 列表页 | 搜索 + 3 筛选 + 7 列 + 4 个行操作 | 进入菜单 |
| 新建供应商 | 完整建档（基础信息 / 资质证照 / 合作协议 / 超管账号 / 供应类型 / 供货商户）+ 开户 | 平台**无**该供应商档案 |
| 建立合作 | 沿用原档案建档，**不可开户**，账号只读回显 | 平台**有**该档案、本租户未合作 |
| 详情 / 编辑 | 分区展示，按「建档租户 / 非建档租户」区分可编辑性 | 行操作「详情 / 编辑」 |
| 超管账号 | 重置密码（仅本租户开通的账号可重置） | 行操作「重置密码」 |
| 合作状态 | 解除合作 / 继续合作 | 行操作 |

## 5. 关键规则

| 编号 | 规则 |
| --- | --- |
| **R1** | **档案唯一**：统一社会信用代码全平台唯一。已存在 → 不重复建档，转为「建立合作」流程 |
| **R2** | **账号唯一**：一个供应商只有一个超管账号。建档时若该供应商在平台已有账号（他租户开的），**禁止再开户**，账号栏只读回显原账号，并提示「该供应商账号已存在，请使用该账号登录供应商系统」 |
| **R3** | **主体信息编辑权**：名称、信用代码、地址、许可证号、三类证照 —— **只有建档租户能改**；改完**实时同步**给所有合作该供应商的租户；非建档租户这些字段只读 |
| **R4** | **租户私有字段**：联系人、联系方式、合作协议、供应类型、供货商户范围 —— **各租户独立维护**，非建档租户也可改，互不影响 |
| **R5** | **营业执照**：必传，1–2 张 |
| **R6** | **食品经营许可证 / 食品生产许可证**：选填；填了证号才能上传图片，各 ≤2 张 |
| **R7** | **合作协议**：选填，≤10 份；**本租户独立签署、不沿用其他租户**；**不留历史协议**，删除即删 |
| **R8** | **供应类型**：毛菜/净菜/半成品，**至少 1 个**，多选；变更只影响**新发起**的采购，在途单据不受影响。建档时提示平台已有类型 |
| **R9** | **供货商户范围**：默认「全部商户」，可改为「指定商户」（≥1 家）；未绑定的商户在采购中选不到该供应商 |
| **R10** | **超管账号**：账号必填（如手机号）且平台唯一；默认密码 `Slw@000000`，**首次登录强制修改**；账号一经开通长期有效，**不设有效期** |
| **R11** | **重置密码**：租户可把超管账号重置为默认密码，首次登录须改密；**非本租户开通的账号不可重置**（行内按钮置灰 + 提示开通租户） |
| **R12** | **解除 / 继续合作**：解除 → 状态「已解除」，商户端不再可选该供应商，**该供应商已产生的询价单、采购订单继续履行**；继续合作 → 随时可回「合作中」 |
| **R13** | **时间字段**：列表展示**创建时间**与**更新时间**，精确到分（`YYYY-MM-DD HH:mm`）；创建时间 = 本租户与供应商建立合作关系的时间，更新时间 = 本租户对该合作关系最近一次维护（编辑、重置密码、解除/继续合作）的时间；**系统自动记录，不记录操作人员** |

## 6. 列表页

| 区域 | 定义 |
| --- | --- |
| 列 | 供应商信息（名称 + 信用代码副行）· 供应类型（标签）· 合作商户（N 家 + 全部商户/指定商户）· 超管账号（账号 + 「本租户开通 / XX租户开通」）· 状态 · **创建时间** · **更新时间** · 操作（共 8 列，两个时间列在操作列之前） |
| 筛选 | 供应类型（全部/毛菜/净菜/半成品）· 合作状态（全部/合作中/已解除）· 账号归属（全部/本租户开户/沿用他租户账号） |
| 搜索 | 供应商名称 / 信用代码 / 账号，模糊匹配 |
| 时间列 | 上行日期（`YYYY-MM-DD`，加粗）+ 下行时分（`HH:mm`，弱化）；两列均左对齐、不折行；**不展示操作人** |
| 行操作 | 详情 · 编辑 · 重置密码 · 解除合作（已解除时显示继续合作） |
| 空态 | 「没有符合条件的供应商」 |

## 7. 新建供应商（字段表）

| 分区 | 字段 | 必填 | 校验 / 说明 |
| --- | --- | --- | --- |
| 基础信息 | 供应商名称 | ✅ | 全称 |
| | 统一社会信用代码 | ✅ | 18 位，可「核验」判断平台是否已有档案 |
| | 供应商地址 | ✕ | 省市区 + 详细地址 |
| | 联系人 | ✅ | — |
| | 联系方式 | ✅ | 11 位手机号 |
| 资质证照 | 营业执照 | ✅ | 1–2 张 |
| | 食品经营许可证号 + 图片 | ✕ | 有号才可传图，≤2 张 |
| | 食品生产许可证号 + 图片 | ✕ | 有号才可传图，≤2 张 |
| 合作协议 | 合作协议 | ✕ | ≤10 份，本租户独立签署 |
| 超管账号 | 账号 | ✅ | 平台唯一；已存在则整体不可开户（R2） |
| | 默认密码 | 系统 | `Slw@000000`，只读，首次登录强制改 |
| 供应类型 | 毛菜 / 净菜 / 半成品 | ✅ ≥1 | 多选；提示平台已有类型 |
| 供货商户 | 商户多选 | ✅ | 默认全部商户；改「指定商户」时至少选 1 家 |

**平台已存在该供应商时的三条分支**

| 场景 | 表现 |
| --- | --- |
| 平台无此档案 | 正常填写全部字段，创建成功后**同时开通超管账号** |
| 平台有此档案、本租户未合作 | 提示「该供应商已存在于平台，本次仅建立本租户的合作关系」；主体信息与证照**带出原档案且只读**；联系人/联系方式默认带出原值**可改**；合作协议为空需本租户自传；账号栏只读回显 + 提示「该供应商账号已存在，请使用该账号登录供应商系统」；按钮变「确认建立合作」 |
| 本租户已合作 | 阻断，提示「该供应商已存在于本租户，请勿重复创建」 |

## 9. 状态机

```
合作中 ──解除合作──► 已解除
   ▲                    │
   └───── 继续合作 ──────┘
```

| 状态 | 商户端可选 | 已产生单据 | 可执行动作 |
| --- | --- | --- | --- |
| 合作中 | ✅ | 继续履行 | 编辑、重置密码、解除合作 |
| 已解除 | ❌ | **继续履行** | 编辑（租户私有字段）、继续合作 |

## 10. 跨租户口径

| 场景 | 租户 A（建档 + 开户） | 租户 B（后加入） |
| --- | --- | --- |
| 建档 | 填写全部字段 → 建档 + 开户 | 平台已有档案 → 沿用档案建立合作，**不可开户** |
| 账号 | 持有，可重置密码 | 只读回显 A 开的账号；重置按钮置灰，提示「该账号由 A 开通，本租户不可重置」 |
| 主体信息 | 可改，改完实时同步给 B | 只读 |
| 联系人 / 联系方式 | 各自独立 | 各自独立 |
| 合作协议 | 自己签的 | 自己签的，看不到 A 的协议 |
| 供应类型 / 供货商户 | 各自独立 | 各自独立 |
| 解除合作 | 只解除与 A 的合作，不影响 B | 只解除与 B 的合作，不影响 A |

| 校验点 | 提示文案 |
| --- | --- |
| 重复创建（本租户已合作） | 该供应商已存在于本租户，请勿重复创建 |
| 平台已有账号 | 该供应商账号已存在（账号 xxx），请使用该账号登录供应商系统 |
| 建立合作时 | 该供应商已存在于平台，本次仅建立本租户的合作关系 |
| 供应类型冲突 | 该供应商在平台已有供应类型：毛菜、半成品 |
| 账号被占用 | 账号「xxx」已被其他供应商使用，请更换 |

## 11. 异常与边界

| # | 场景 | 处理 |
| --- | --- | --- |
| 1 | 信用代码格式不对 | 「请输入正确的 18 位统一社会信用代码」 |
| 2 | 账号与他人重复 | 「账号「xxx」已被其他供应商使用，请更换」 |
| 3 | 执照未传 / 超 2 张 | 阻断提交 / 超出不可再加 |
| 4 | 合作协议超 10 份 | 超出不可再加，逐张可删 |
| 5 | 供应类型一个都没选 | 阻断提交 |
| 6 | 选「指定商户」但没勾 | 阻断，至少 1 家 |
| 7 | 本租户无商户 | 范围为空，提示「暂无商户可绑定」，可先建档后补 |
| 8 | 解除合作后商户端仍有历史单据引用 | 正常展示与履行，仅禁止**新增**采购 |

## 12. 验收要点

| AC | 用例 | 预期 |
| --- | --- | --- |
| AC01 | 平台无此档案新建 | 建档成功 + 同时生成超管账号，列表出现该供应商（本租户开通） |
| AC02 | 新建时不传营业执照 | 阻断提交 |
| AC03 | 信用代码与已有档案重复 | 转为「建立合作」，不新建档案 |
| AC04 | 本租户已合作再次新建 | 阻断并提示勿重复创建 |
| AC05 | 租户 B 建立合作 | 主体信息与证照只读、自动带出；联系人/联系方式可改；合作协议需自己传 |
| AC06 | 租户 B 的账号栏 | 只读回显 A 的账号 + 提示「请使用该账号登录供应商系统」；无开户入口 |
| AC07 | 租户 A 改名称/地址 | 保存后租户 B 侧实时看到新值 |
| AC08 | 租户 A 改营业执照 | 同上，B 侧证照同步更新 |
| AC09 | 租户 B 改联系人/联系方式 | 只影响 B，A 侧不变 |
| AC10 | 租户 B 上传合作协议 | 只在 B 可见，A 侧协议数量不变 |
| AC11 | 供应类型一个都不选 | 阻断提交，提示至少选 1 个 |
| AC12 | 供货商户默认值 | 默认全选本租户商户，可取消部分；改指定时至少 1 家 |
| AC13 | 重置密码（本租户开通） | 二次确认后重置为 `Slw@000000`，详情「最近重置」更新 |
| AC14 | 重置密码（他租户开通） | 按钮置灰不可点，`title` 说明开通租户 |
| AC15 | 解除合作 | 状态变「已解除」；商户端不可再选；历史单据仍可查看与履行 |
| AC16 | 继续合作 | 状态回「合作中」，商户端恢复可选 |
| AC17 | 筛选「沿用他租户账号」 | 只列出账号归属为他租户的供应商 |
| AC18 | 新建供应商保存 | 新行创建时间与更新时间均为当前时刻，精确到分 |
| AC19 | 编辑 / 重置密码 / 解除或继续合作后 | 该行更新时间刷新为当前时刻；创建时间不变 |
| AC20 | 查看任意一行的时间列 | 只显示日期与时分，**任何位置都不出现操作人姓名或账号** |

## 附录A 与商户端供应商管理的关系

| 维度 | 租户端（本文档） | 商户端（只读引用） |
| --- | --- | --- |
| 数据来源 | 建档 + 维护合作关系 | 只读本租户「合作中」的供应商 |
| 可见范围 | 本租户全部合作供应商 | 只显示**供货商户范围**包含自己的供应商 |
| 可操作性 | 建档、开户、改档案、解除/继续合作 | 仅查看详情，无任何写操作 |
| 已解除 | 列表保留并可恢复 | 直接不可见 |

> 商户端详情不出现「超管账号」「合作协议」等租户私有信息，只展示基础信息、资质证照、供应类型、供货范围。
