## 角色、账号与权限关系（跨页）

> 来源：`../运营端-系统管理运营账号与权限-PRD.md#3.1 关系规则`

| 规则 | 说明 |
| --- | --- |
| 账号与角色 | 一个运营账号只能绑定一个运营角色；一个运营角色可以关联多个运营账号 |
| 权限来源 | 账号的功能权限和数据权限全部继承自所属角色，不在账号上单独配置 |
| 角色改动 | 修改角色权限后，该角色下全部账号同步使用最新权限 |
| 换角色 | 修改账号所属角色后，账号使用新角色的权限，旧角色权限失效 |
| 超级管理员角色 | 系统内置角色，只允许查看，不允许分配给普通运营账号 |
| 超级管理员账号 | 全系统仅有一个，不属于普通运营子账号，不在「运营账号」列表中展示 |

角色列表与账号列表看到的功能权限、数据权限是同一套继承关系的结果，改动任一侧都会互相影响。

### 权限判断顺序

账号执行业务操作时按以下顺序判断，任意一项不满足时不允许继续操作：

1. 账号状态是否为正常。
2. 所属角色状态是否为启用。
3. 角色是否拥有对应页面及操作的功能权限。
4. 当前业务数据是否处于账号允许操作的数据范围内。

即：**停用账号** 或 **停用角色** 都会让账号整体不可用，与该角色是否配置了权限无关。

## 角色与账号变更的业务影响（跨页）

> 来源：`../运营端-系统管理运营账号与权限-PRD.md#13. 业务影响规则`、`#4.3.2 数据权限`

| 变更 | 影响 |
| --- | --- |
| 修改角色功能权限 | 影响该角色下全部账号；新增权限后关联账号可以使用对应功能，移除权限后不再显示或使用对应功能；不影响账号历史操作记录和已经创建的数据 |
| 修改角色数据范围 | 改为「全部数据」：账号可以查看和操作其他运营人员创建的数据；改为「仅本人创建」：账号只能查看和操作本人创建的数据，且不能再进入不属于本人的业务数据详情 |
| 停用账号 | 停止该人员继续登录和操作；保留账号、历史记录和已创建业务数据 |
| 停用角色 | 角色不再允许分配；关联账号暂时失去该角色提供的业务权限；重新启用角色后，关联账号恢复角色权限 |

### 数据权限「仅本人创建」的作用范围

同时限制以下操作：查看列表和详情、编辑、删除、发布和下架、授权和撤销授权、导出。

「仅本人创建」的限制覆盖所有功能模块数据，不设例外。

## 首次登录密码提醒（跨页 · 登录侧规则）

> 来源：`../运营端-系统管理运营账号与权限-PRD.md#7. 首次登录密码提醒`

满足以下任一条件时展示提醒：

- 账号首次成功登录。
- 管理员执行过「重置密码」，且账号重置后首次成功登录。

弹窗内容：提示用户当前正在使用初始密码，建议立即修改。

| 操作 | 结果 |
| --- | --- |
| 立即修改 | 进入修改密码流程 |
| 暂不修改 | 关闭弹窗并进入系统 |
| 右上角关闭 | 效果与「暂不修改」一致 |

提醒规则：

- 每次账号创建或密码重置后只提醒一次。
- 用户完成修改后，后续登录不再提醒。
- 用户关闭或选择暂不修改后，后续登录也不再提醒。
- 是否修改密码不影响账号原有功能权限和数据权限。

> 该弹窗已单独出原型：`登录页-首次登录改密提醒.html`（登录页范围）。

## 本页规则 · 运营角色与权限

> 来源：`../运营端-系统管理运营账号与权限-PRD.md#4. 运营角色与权限`

### 页面职责

统一维护运营角色，为角色配置功能权限和数据权限，并查看角色关联的运营账号。

### 列表范围与筛选

- 搜索框按 **角色名称或角色说明** 模糊匹配，**最多输入 50 个字符**（原型输入框不限制长度，由前端开发按此上限实现）。
- 状态筛选为单选，取值：全部状态 / 启用 / 停用，默认「全部状态」。
- 关键词与状态下拉都是「草稿」条件：输入或选择后**不会立即过滤**，需要点击「搜索」按钮才生效。
- 「重置」清空所有筛选条件（关键词 + 状态下拉）并恢复完整列表。

### 不可违反的约束

- 超级管理员为系统内置角色，**只允许查看，不可编辑**；其角色名称和最高权限属性不可删除，也不允许分配给普通运营账号（列表中以「系统内置角色」标记）。
- 已关联账号的角色不可删除；无关联账号的普通角色才可删除。

### 数据说明

原型中的角色名称、说明、状态、权限和数据范围均为演示数据；刷新后新增、编辑、启停等临时操作恢复为初始演示状态。

## 列表字段与操作列

> 来源：`../运营端-系统管理运营账号与权限-PRD.md#4.2.3 列表字段`、`#12. 数据来源与展示规则`

| 字段 | 内容与约束 |
| --- | --- |
| 角色名称 | 展示角色名称；超级管理员额外标记「系统内置角色」 |
| 角色说明 | 展示角色职责和适用范围，来自新增或编辑角色时填写 |
| 功能权限 | 超级管理员显示「全部功能」；普通角色显示已选权限项数量 |
| 数据权限 | 全部数据、仅本人创建；来自角色配置 |
| 关联账号 | 按实际绑定该角色的账号数量 **动态统计**，不是静态字段。超级管理员账号不在运营账号列表中展示，但**仍计入**角色的关联账号统计，因此超级管理员角色显示 1 个关联账号 |
| 状态 | 启用、停用 |

### 操作列

> 来源：`../运营端-系统管理运营账号与权限-PRD.md#4.6 查看角色详情`、`#4.7 编辑角色`、`#4.8 角色状态流转`、`#4.9 删除角色`

| 动作 | 条件与结果 |
| --- | --- |
| 查看 | 打开只读详情抽屉；功能权限仅展示，不允许在详情抽屉中直接修改。所有角色都可以查看 |
| 编辑 | 打开编辑抽屉并回显角色名称、状态、角色说明、数据权限、功能权限树及已选状态；保存后新权限同步影响该角色关联的全部运营账号。**超级管理员为系统内置角色，不提供编辑入口** |
| 启用 / 停用 | 启用：可以分配给新建或编辑的运营账号，关联账号可以按角色权限使用运营端。停用：不再出现在账号角色选择列表中，已关联账号保留角色关系但该角色权限暂时失效，需要更换为启用角色或等待角色重新启用；停用角色不会删除历史操作记录和已创建业务数据。超级管理员不提供该入口 |
| 删除 | 系统内置角色不可删除；已关联账号的角色不可删除并提示关联账号数量；无关联账号的普通角色可以删除；删除后不再出现在角色列表和账号角色选择项中 |

提示文案：删除有关联账号的角色 → `该角色已关联N个账号，不能删除`。

超级管理员角色（系统内置）的操作列只有「查看」：不提供编辑、启用/停用与删除入口。编辑入口即便被绕过调用也会被拒绝，提示 `系统内置角色不可编辑`。

## 本页规则 · 新增运营角色

> 来源：`../运营端-系统管理运营账号与权限-PRD.md#4.3 新增运营角色`、`#4.5 保存角色`

点击「保存」时必须全部通过：

1. 角色名称已填写且长度符合要求。
2. 角色名称不存在重复。
3. 已选择数据权限。
4. 至少选择一项功能权限。

校验通过后：

- 新角色进入角色列表。
- 启用状态的角色可以立即分配给运营账号。
- 停用状态的角色不能分配给运营账号。

原型只校验「角色名称非空」与「至少选择一项功能权限」；长度与重名校验不在原型实现，由前端开发按下文字段约束实现。

> 来源：`../运营端-系统管理运营账号与权限-PRD.md#4.3.2 数据权限`

## 功能权限树

> 来源：`../运营端-系统管理运营账号与权限-PRD.md#4.4 功能权限树`、`#4.4.1 勾选联动`

三级树形结构：一级业务模块 → 二级业务页面 → 三级页面操作。

| 一级模块 | 二级页面 | 三级操作 |
| --- | --- | --- |
| 商品中心 | 标准食材 | 查看 |
| 商品中心 | 运营商品 | 查看、新增、编辑、发布、下架 |
| 商品中心 | SKU中心 | 查看、编辑、停用 |
| 商品中心 | 发布记录 | 查看 |
| 授权管理 | 商品授权 | 查看、新建、撤销 |
| 授权管理 | 菜谱授权 | 查看、新建、撤销 |
| 基础数据 | 品牌库 | 查看、新增、编辑、删除 |
| 基础数据 | 分类库 | 查看、新增、编辑、删除 |
| 系统管理 | 运营角色与权限 | 查看、维护 |
| 系统管理 | 运营账号 | 查看、新增、编辑、启停、重置密码 |

### 勾选联动

1. 勾选一级模块时，自动勾选该模块下全部页面和操作；取消一级模块时，自动取消该模块下全部页面和操作。
2. 勾选二级页面时，自动勾选该页面下全部操作；取消二级页面时，自动取消该页面下全部操作。
3. 只选择部分下级权限时，上级节点显示半选状态。
4. 角色至少需要选择一项功能权限才能保存。

### 权限落到账号上的效果

- 账号没有页面「查看」权限时，不显示对应菜单。
- 账号没有某项操作权限时，不显示或不可使用对应操作按钮。

## 保存

> 来源：`../运营端-系统管理运营账号与权限-PRD.md#4.5 保存角色`、`#14. 页面提示与异常反馈`

点击「保存」时的校验与提示：

| 校验 | 不通过的提示 |
| --- | --- |
| 角色名称已填写且长度符合要求 | `请输入角色名称` |
| 角色名称不存在重复 | `角色名称已存在` |

## 本页规则 · 编辑运营角色

> 来源：`../运营端-系统管理运营账号与权限-PRD.md#4.7 编辑角色`

打开时回显：角色名称、状态、角色说明、数据权限、功能权限树及已选状态。

保存后，新权限同步影响该角色关联的全部运营账号：

- 新增权限后，关联账号可以使用对应功能。
- 移除权限后，关联账号不再显示或使用对应功能。
- 不影响账号历史操作记录和已经创建的数据。

系统内置超级管理员角色：不可编辑，角色名称和最高权限属性不可删除；不允许将该角色分配给普通运营账号。原型对内置角色只提供「查看」，不提供编辑入口；即使绕过入口调用编辑也会被拒绝，提示 `系统内置角色不可编辑`。

字段约束、数据权限、功能权限树与保存校验同「新增运营角色」。

## 关联账号（数量）

> 来源：`../运营端-系统管理运营账号与权限-PRD.md#4.6.2 关联账号`

标题展示「关联账号（数量）」，数量按实际账号动态计算。

每个关联账号展示：姓名、手机号码、账号状态；姓名与手机号码组合展示，例如 `张三 13758214560`。

超级管理员角色会在这里展示超级管理员账号（姓名 + 手机号 + 状态）；它只是不出现在运营账号列表中，角色侧的关联关系照常统计。

## 本页规则 · 运营账号

> 来源：`../运营端-系统管理运营账号与权限-PRD.md#5. 运营账号`、`#10. 账号状态流转`

### 列表范围

- 列表只展示普通运营子账号。
- 系统唯一的超级管理员账号不在列表中展示。
- 超级管理员仍可登录系统并维护普通运营账号。

### 筛选

- 关键词按 **姓名、手机号或角色名称** 模糊搜索，**最多输入 50 个字符**（原型输入框不限制长度，由前端开发按此上限实现）。
- 角色为单选，**只展示启用中的普通运营角色**，不展示超级管理员角色。
- 状态：全部状态、正常、停用。
- 关键词与两个下拉都是「草稿」条件：输入或选择后**不会立即过滤**，需要点击「搜索」按钮才生效。
- 「重置」清空所有筛选条件（关键词 + 角色下拉 + 状态下拉）并恢复完整列表。

### 状态流转与限制

- 正常 ⇄ 停用。
- 停用后不允许登录运营端，已登录状态应结束；不删除账号历史操作记录，也不删除该账号创建的商品、授权、品牌、分类等业务数据，这些数据仍可被拥有「全部数据」权限的账号查看和操作。
- 普通运营账号不能停用自己的账号：列表用「当前登录账号」标识当前登录的账号，该行的启用/停用按钮不显示。
- 超级管理员账号不能在运营账号列表中被停用。
- 系统始终保留唯一的超级管理员账号。

> 原型演示：列表把「周雨」标记为当前登录账号，用于演示自停用限制。

### 数据说明

原型中的姓名、手机号、角色和登录时间均为演示数据；刷新后新增、编辑、启停等临时操作恢复为初始演示状态。

## 列表字段与操作列

> 来源：`../运营端-系统管理运营账号与权限-PRD.md#5.5 列表字段`、`#12. 数据来源与展示规则`

| 字段 | 内容与约束 |
| --- | --- |
| 运营人员 | 姓名；当前登录的账号额外标记「当前登录账号」 |
| 登录手机号 | 11 位手机号码，也是登录账号；创建后不可修改 |
| 所属角色 | 当前账号绑定的唯一角色 |

> 来源：`../运营端-系统管理运营账号与权限-PRD.md#8. 查看运营账号`、`#9. 编辑运营账号`、`#10. 账号状态流转`、`#11. 重置密码`

| --- | --- |
| 查看 | 打开只读详情抽屉，不直接修改账号信息 |
