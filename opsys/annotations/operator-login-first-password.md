## 本页规则 · 登录流程

> 来源：`../运营端-系统管理运营账号与权限-PRD.md#5.3 页面提示`、`#6.2 初始密码`、`#7.1 触发条件`

### 进入方式

原型默认已处于登录状态（演示账号：周雨）。点击右上角当前账号姓名，选择「退出登录」后回到登录页；重新登录成功才回到运营端。

### 登录凭据

- 手机号为唯一登录账号。
- 新账号的初始密码由管理员创建账号时生成，统一为 `slw@000000`，用户不能自行设定初始密码。

### 首次登录提醒的触发条件

满足以下任一条件时，登录成功后展示改密提醒弹窗：

1. 账号首次成功登录。
2. 管理员执行过「重置密码」，且账号重置后首次成功登录。

> 登录页提供演示账号（陈晨 / 周雨 / 王蕾），点击即可填入登录框，分别对应「首次登录待提醒」「登录不再提醒」「已停用」三种表现。
> 登录成功后，运营账号列表中的「当前登录账号」标识会跟着切换。

### 提醒只消费一次

- 每次账号创建或密码重置后只提醒一次。
- 完成修改、关闭弹窗、或选择「暂不修改」之后，后续登录都不再提醒。
- 是否修改密码不影响账号原有功能权限和数据权限。

登录校验与失败提示文案见「登录表单字段」。

## 退出登录

> 来源：`../运营端-系统管理运营账号与权限-PRD.md#5.3 页面提示`、`#10.3 特殊限制`

右上角展示当前登录账号（姓名 + 所属角色），点击展开菜单，菜单内提供「退出登录」。

- 退出后回到登录页，必须重新通过登录校验才能进入运营端。
- 一个运营子账号只能绑定一个角色，因此右上角只展示单一角色名称。
- 账号被管理员停用后，已登录状态应结束：下次进入需要重新登录，且登录会被拒绝（提示 `该账号已被停用，请联系管理员`）。

> 原型用右上角账号菜单承载登录流程演示：退出 → 登录校验 → 首次登录改密提醒 → 修改密码。

## 登录表单字段

> 来源：`../运营端-系统管理运营账号与权限-PRD.md#5.3 页面提示`、`#10.3 特殊限制`

| 字段 | 必填 | 格式 | 规则 |
| --- | --- | --- | --- |
| 登录手机号 | 是 | 11 位中国大陆手机号码 | 手机号为唯一登录账号；停用状态账号不允许登录 |
| 登录密码 | 是 | — | 初始密码为 `slw@000000`，重置密码后同样恢复为该值 |

### 登录校验与提示文案

| 触发条件 | 提示文案 |
| --- | --- |
| 手机号不是 11 位手机号码 | `请输入正确的11位手机号码` |
| 密码未填写 | `请输入登录密码` |
| 手机号未注册，或密码错误 | `手机号或密码错误` |
| 账号状态为停用 | `该账号已被停用，请联系管理员` |

- 不区分「手机号未注册」和「密码错误」，统一提示 `手机号或密码错误`，避免通过登录页枚举平台已有哪些账号。
- 停用提示在凭据校验通过之后才给出：密码错误时仍返回 `手机号或密码错误`，不暴露该手机号对应账号的停用状态。
- 暂不做连续错误次数限制与账号锁定。

登录校验不通过时停留在登录页并清空错误提示（重新输入即清除），不进入后续的改密提醒流程。

## 登录

> 来源：`../运营端-系统管理运营账号与权限-PRD.md#7.1 触发条件`、`#10.3 特殊限制`

点击「登录」后按以下顺序判断：

| 判断 | 结果 |
| --- | --- |
| 手机号格式、密码必填校验 | 不通过则停留在登录页并提示对应文案 |
| 手机号与密码匹配 | 不匹配（含手机号未注册）提示 `手机号或密码错误` |
| 账号状态 | 停用 → 提示 `该账号已被停用，请联系管理员`，不允许登录 |
| 首次登录提醒状态 | 待提醒（首次登录，或重置密码后首次登录）→ 登录成功并弹出改密提醒弹窗 |
| 首次登录提醒状态 | 已处理 → 登录成功，直接进入运营端，不再提醒 |

停用账号不允许登录运营端；已登录状态应结束（§10.3，登录侧只负责拦截）。

## 本页规则 · 首次登录改密提醒

> 来源：`../运营端-系统管理运营账号与权限-PRD.md#7.2 弹窗内容与操作`、`#7.3 提醒规则`

弹窗在登录成功后展示，提示用户当前正在使用初始密码，并给出两个操作：立即修改、暂不修改。右上角关闭与「暂不修改」效果一致。

提醒只消费一次：本次关闭或修改之后，后续登录都不再提醒（包括该账号被再次重置密码之前的全部登录）。
<!-- anno:end id=login-reminder-rules -->

<!-- anno:start id=login-reminder-content -->
## 弹窗内容

> 来源：`../运营端-系统管理运营账号与权限-PRD.md#7.2 弹窗内容与操作`

提示用户当前正在使用初始密码，建议立即修改。

初始密码为固定值 `slw@000000`，弹窗中直接展示该值，方便用户理解「正在使用初始密码」的含义。
<!-- anno:end id=login-reminder-content -->

<!-- anno:start id=login-reminder-actions -->
## 弹窗操作

> 来源：`../运营端-系统管理运营账号与权限-PRD.md#7.2 弹窗内容与操作`

| 操作 | 结果 |
| --- | --- |
| 立即修改 | 进入修改密码流程（本原型打开修改密码弹窗） |
| 暂不修改 | 关闭弹窗并返回运营端；本次提醒已消费，后续登录不再提醒 |
| 右上角关闭 | 效果与「暂不修改」一致，后续登录不再提醒 |

两个入口都不要再提示第二次：提醒状态在离开弹窗时就应置为「已处理」。
<!-- anno:end id=login-reminder-actions -->

## 本页规则 · 修改密码

> 来源：`../运营端-系统管理运营账号与权限-PRD.md#7.2 弹窗内容与操作`

「立即修改」进入修改密码流程，需要填写**原密码**并设置新密码。

### 密码规则

- 新密码长度 **8～20 个字符**。
- 必须**同时包含**大写字母、小写字母、数字、特殊字符。
- 新密码不能与原密码相同。

### 失败提示文案

| 触发条件 | 提示文案 |
| --- | --- |
| 原密码未填写 | `请输入原密码` |
| 原密码不正确 | `原密码不正确` |
| 新密码未填写 | `请输入新密码` |
| 新密码不满足长度或字符类型要求 | `密码需为8-20个字符，且包含大小写字母、数字和特殊字符` |
| 新密码与原密码相同 | `新密码不能与原密码相同` |
| 两次输入的新密码不一致 | `两次输入的新密码不一致` |

修改成功后返回运营端，且本次提醒已消费。
<!-- anno:end id=login-change-rules -->

## 修改密码表单

> 来源：`../运营端-系统管理运营账号与权限-PRD.md#7.2 弹窗内容与操作`

| 字段 | 必填 | 规则 |
| --- | --- | --- |
| 原密码 | 是 | 需与当前登录密码一致，否则提示 `原密码不正确` |
| 新密码 | 是 | 8～20 个字符，且同时包含大写字母、小写字母、数字、特殊字符 |
| 确认新密码 | 是 | 必须与新密码一致 |

提交成功后：返回运营端，本次提醒已消费，后续登录不再提醒；是否修改密码不影响账号原有功能权限和数据权限。
